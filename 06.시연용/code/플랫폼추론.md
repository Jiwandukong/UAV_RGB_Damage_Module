# 플랫폼에서 원본 사진 추론 호출

입력은 **원본 JPG/PNG 한 장 또는 사진 폴더**입니다. 손상 라벨과 학습 데이터는 필요하지 않습니다.
출력은 예측 손상의 CSV·Excel, 원본 사진, 512×512 원본·모델 오버레이, 이미지 연결 정보입니다.

## 실행

프로젝트와 SAM3 패키지를 설치하고 [시연 모델](../02.시연모델/README.md) 및 [기존 OBJ](../../01_RawData/geometry/README.md)를 준비합니다. 아래 명령은 `06.시연용/`에서 실행합니다.

```bash
python code/시연도구.py infer \
  --images /path/to/photo.JPG \
  --model-record 02.시연모델/손상타일489개_512입력_20회학습/학습기록.json \
  --mesh ../01_RawData/geometry/daecheong_dam_epsg5186_zup.obj \
  --output /path/to/new_result \
  --device cuda
```

- `--images`: 사진 한 장 또는 폴더. 폴더는 바로 아래 JPG·JPEG·PNG를 모두 처리합니다.
- `--output`: 새 결과 폴더. 기존 경로는 덮어쓰지 않으므로 요청마다 다른 폴더를 지정합니다.
- `--device cuda`: 모델 추론에 GPU 사용. `auto`는 GPU가 있으면 사용하고 없으면 CPU를 선택합니다. 이 시연 모델의 전체 실데이터 검증은 GPU 기준입니다.
- `--model-record`: 배포 모델의 파일명과 검증 정보. 사용자 손상 라벨 파일이 아닙니다.

사진 크기를 바꾸지 않으며 모든 영역을 처리합니다. 촬영 위치·방향·초점 정보가 없거나 3D 계산에 실패하면 픽셀 결과와 이미지는 유지하고 좌표·물리 정량값은 비웁니다. 원본·기존 모델·라벨 참고 결과는 변경하지 않습니다.

## 반환 결과

정상 종료 코드는 `0`입니다. 완료된 `--output` 폴더의 `damage_results.csv` 또는 `damage_results.xlsx`를 읽으십시오. 진행 메시지는 처리 중 표준 출력에 표시됩니다.

`source_image_path`, `tile_original_paths_json`, `tile_overlay_paths_json`은 모두 해당 결과 폴더 기준 상대경로입니다. `tile_overlay_paths_json`은 **모델 예측 오버레이**를 가리킵니다. 두 타일 배열은 같은 순서이며 첫 항목은 대표 표시점에 대응하는 타일입니다.

표출용·정량용 컬럼은 [산출물 설명](../04.시연산출물/모델추론결과/README.md)을 참고하십시오. 손상 ID는 요청별 결과 묶음 안에서만 유일합니다. 실제 플랫폼 화면 구현은 별도입니다.
