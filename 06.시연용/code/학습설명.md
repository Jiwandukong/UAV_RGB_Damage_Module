# 시연용 학습 담당자 안내

## 입력과 정답

- 실제 RGB 입력, 학습 정답, 최종 예측 크기: 512×512.
- `Sam3Processor`의 512→1008 Resize를 호출하지 않습니다. 1008 RGB 캔버스도 만들지 않습니다.
- CRC는 원본 좌표에서 반올림 후 `PIL.ImageDraw.line(width=1)`로 생성하고 타일로 자릅니다. 안티앨리어싱·팽창·정답 축소를 하지 않습니다. 교차점이나 여러 선이 인접한 부분은 자연스럽게 여러 픽셀을 차지할 수 있습니다.
- DLM/SPL은 각각 독립적인 다각형 마스크입니다. 겹친 클래스는 그대로 보존합니다.
- `positive_pixels[class] > 0`인 타일·클래스 쌍만 학습합니다. 전체 1,760타일 중 489타일, 650쌍(CRC262 / DLM112 / SPL276)이 대상입니다. 선택된 타일 내부의 배경은 유지합니다.
- 가장자리 여백은 `VALID` 마스크로 손실에서 제외합니다. 실제 원본 사진 영역의 정상 배경은 손상과 구분하도록 손실에 포함합니다.

현재 생성 데이터는 Pillow12.2.0/libjpeg-turbo3.1.4.1, NumPy1.26.4에서 확인했습니다. JPEG 디코더나 다각형 래스터화 라이브러리 버전이 다르면 재생성 픽셀에 차이가 날 수 있습니다. 정확히 동일한 결과가 필요하면 준비된 타일/마스크를 사용하거나 같은 버전을 사용하십시오. 원본 파일의 바이트는 항상 별도로 보존합니다.

## 기존 SAM3와의 차이

기존 AUG512는 자른 영상이 512여도 모델 처리 해상도는 1008이었습니다. 기존 파일은 수정하지 않고 새 모델 인스턴스만 조정합니다.

SAM3의 패치 간격은 14이며 512는 14의 배수가 아닙니다. 마지막 8픽셀을 버리지 않기 위해 패치 합성곱에 내부 3픽셀 패딩을 적용하여 37×37 토큰을 만듭니다. 이는 사진을 확대하거나 모델에 518/1008 크기의 RGB 영상을 넣는 것이 아닙니다. 글로벌 위치 인코딩과 좌표 캐시도 새 토큰 격자에 맞춥니다. 기존 가중치의 형태는 바꾸지 않습니다.

분할 출력은 내부 148×148 logits를 518 영역으로 보간하고 패딩 3픽셀을 제거해 원본 512 좌표에 돌려놓습니다. **입력 이미지나 1픽셀 정답을 리사이즈하는 과정이 아닙니다.** 작은 분할 출력으로 1픽셀 정답을 학습하므로, 실제 예측이 반드시 1픽셀 두께이거나 정답과 완전히 일치한다고 보장하지 않습니다.

학습·예측은 SAM3에 이미 있는 텍스트 조건부 `semantic_seg` 출력을 사용합니다. **기존 코드의 점수 필터링된 인스턴스 마스크 합집합과는 다른 출력 경로입니다.** 새 분할 헤드를 임의로 추가하지 않으며, 이 차이는 모델 기록에 남깁니다. CRC/DLM/SPL 질의는 각각 crack/delamination/spalling입니다.

초기 학습 예제는 영상·텍스트 백본을 보존하고, 융합 인코더와 픽셀/semantic 분할부를 추가 학습합니다. 전체 SAM3 가중치를 모두 학습하는 설정은 아닙니다. 손실은 원본 512 격자의 양성/음성 픽셀 균형 BCE + Dice입니다. 학습 타일/질의에 음성 샘플을 추가하지 않는 것과, 양성 타일 내부 배경 픽셀을 손실에 사용하는 것은 구분됩니다.

기존 ViT의 추론용 fused MLP는 autograd를 허용하지 않으므로 새 인스턴스에서만 동일한 기존 Linear/GELU 레이어의 미융합 연산을 사용합니다. upstream 코드 파일과 기존 모델은 수정하지 않습니다.

## 체크포인트·의존성

초기 체크포인트의 SHA256 `a2749dba62207575afac9ed42f923d7cdfd7e2d2f0ffb2210a103e91657d985d`를 확인한 뒤 모든 모델 가중치를 strict load합니다. 학습 결과는 모델 가중치와 시연 설정을 저장하고, 학습기록에 새 해시를 남깁니다. 기존 체크포인트의 optimizer/epoch를 이어받지 않습니다. 현재 예제에는 중단 지점 resume 기능이 없습니다.

SAM3 0.1.0 및 현재 프로젝트의 PyTorch 환경을 사용합니다. 필요하면 `SAM3_SOURCE=/path/to/sam3`로 SAM3 체크아웃을 지정할 수 있습니다. 실행 시 사용한 소스 해시를 학습기록에 남깁니다. 이 경로는 기존 추론 라이브러리와 직접 autograd를 사용하므로 Hydra 기반 공용 학습기의 추가 패키지는 사용하지 않습니다.

## 확인 방법

```bash
python -m pytest tests code/tests -q
```

512가 아닌 입력 거부, 마지막 행·열의 패치 포함, 패딩 이후 출력 좌표 복원, 1픽셀 CRC, 타일 경계, 양성 타일만 학습, 유효영역 손실을 검사합니다. GPU에서 실제 학습과 체크포인트 재로딩은 별도 점검 명령으로 확인합니다. 학습 단계가 완료된 기록과 일반화 성능/최종 시연 품질 검증은 구분합니다.
