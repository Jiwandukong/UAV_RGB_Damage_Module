# 시연용 실행 안내

플랫폼 표출만 필요하면 [준비된 결과 위치](../README.md)를 참고하십시오. 아래는 라벨 자료 재생성·추가 학습·타일 비교를 진행하는 담당자용입니다.

**원본 사진 입력부터 모델 추론 CSV·오버레이까지 생성하려면 [플랫폼 추론 명령](플랫폼추론.md)을 사용하십시오.** 아래 `prepare`·`quantify`는 라벨 기반 참고 자료용 명령입니다.

## 실행 환경

아래 명령은 모두 **`06.시연용` 폴더 안에서** 실행합니다. 다른 번호의 폴더나 상위 프로젝트 설치는 필요하지 않습니다.

Python 3.11 환경에 필요한 패키지를 설치합니다.

```bash
python -m pip install -r requirements.txt
```

라벨 기반 정량 생성에는 SAM3 모델·패키지가 필요하지 않습니다. 학습·모델 추론을 할 때는 [독립 실행 설치 안내](플랫폼추론.md#처음-한-번-설치)에 따라 공식 SAM3 패키지도 설치하십시오. 검증 버전은 `46957e47805eaa273f4aa7bbbd25a88bca9108ce`입니다.

출력 폴더가 이미 있으면 덮어쓰지 않습니다.

## 1. 원본에서512학습 데이터 준비

```bash
python code/시연도구.py prepare \
  --source 01.시연데이터/원본자료/Daechung_Demo20_GT_release_v1 \
  --output 01.시연데이터/새_512데이터
```

사진을 확대·축소하지 않습니다. CRC는1픽셀 중심선, DLM/SPL은 독립 다각형 마스크로 준비합니다. 배경 타일도 준비되지만 학습에서는 제외하며, 사진 밖 여백은 손실과 정량 계산에서 제외합니다.

## 2. 라벨 기반 정량 산출물 생성 — 모델·GPU 불필요

기존 OBJ를 [이 폴더의 3D 모델 안내](../02.시연모델/댐3D모델/README.md)에 따라 준비한 뒤 실행합니다.

```bash
python code/시연도구.py quantify \
  --data 01.시연데이터/새_512데이터 \
  --output 04.시연산출물_재생성 \
  --mesh 02.시연모델/댐3D모델/daecheong_dam_epsg5186_zup.obj
```

CSV·Excel·원본사진·512원본타일·반투명 라벨 오버레이·계산 기록을 새 폴더에 생성합니다. 기본 좌표·정량 계산은 CPU입니다. 정량값의 의미와 빈칸 기준은 [산출물 안내](../04.시연산출물/README.md)를 확인하십시오.

## 3. 추가 학습 — GPU 필요

추가 학습에만 약 10GB의 기존 `checkpoint_final.pt`가 필요합니다. [기존 기본 모델 Release](https://github.com/Jiwandukong/UAV_RGB_Damage_Module/releases/tag/sam3-aug512-v1)의 분할 파일을 복원하거나 관리자에게 완성 파일을 직접 전달받아 `02.시연모델/추가학습용/checkpoint_final.pt`에 놓으십시오. 이 파일은 3.37GB 시연 모델과 다릅니다.

아래는 20회 학습 명령입니다.

```bash
python code/시연도구.py train \
  --data 01.시연데이터/새_512데이터 \
  --checkpoint 02.시연모델/추가학습용/checkpoint_final.pt \
  --output 02.시연모델/새_20회학습 \
  --epochs 20 --save-every 5
```

손상이 있는489타일의 양성 타일·종류650쌍만 학습합니다. 존재하지 않는 손상 종류를 음성 질의로 추가하지 않습니다. 같은 사진을 학습과 시연에 쓰므로 일반화 성능 평가가 아닙니다. 실행 점검만 하려면 `--epochs 1 --max-steps 6`을 지정할 수 있으나,6단계 결과는 완성 모델이 아닙니다.

## 4. 실제 모델로512타일 한 장 예측

[시연 모델](../02.시연모델/README.md)을 다운로드한 뒤 실행합니다. 현재 저장된 예측은 GPU 환경에서 확인했으며, 이 시연 모델의 CPU 추론은 별도 실행 검증이 필요합니다.

```bash
python code/모델받기.py
python code/시연도구.py predict \
  --image 04.시연산출물/512원본타일/DJI_20250702160538_0800_V__x03584_y01024.png \
  --model-record 02.시연모델/손상타일489개_512입력_20회학습/학습기록.json \
  --output 03.모델예측/새_한장예측
```

라벨을 읽지 않고 모델로만 예측하며, 결과는 라벨과 동일하지 않습니다. 원본 타일·종류별 예측 마스크·모델 오버레이를 따로 저장합니다. 사진 가장자리의 검은 여백이 있는 타일은 연결정보의 유효 폭·높이를 `--valid-width`, `--valid-height`로 전달해야 합니다.

## 5. 새로 학습한 모델의 전체 타일 예측·비교

```bash
python code/시연도구.py predict-batch \
  --data 01.시연데이터/새_512데이터 \
  --model-record 02.시연모델/새_20회학습/학습기록.json \
  --output 03.모델예측/새_전체타일_비교 \
  --selection positive
```

이 **라벨 비교 명령**은 학습에 사용한 것과 동일한 `dataset.json`의 해시를 검사합니다. 공개 원본자료를 새로 준비한 목록은 기존 학습 당시 목록과 다르므로, 기존 모델을 이 명령으로 비교하려면 관리자에게 학습 당시 데이터 묶음을 요청하십시오. 위 명령처럼 새 데이터로 새 모델을 학습한 경우에는 같은 새 데이터를 사용하면 됩니다. **원본 사진 추론인 `infer`에는 이 데이터 묶음이 필요하지 않습니다.**

배치 결과는 각 타일에서세 종류를 모두 예측한 뒤 라벨과 비교합니다. 라벨 오버레이와 실제 모델 오버레이를 구분하며, 모델 예측을 라벨로 보정하지 않습니다.

## 6. 저장된 배치 오버레이의 투명도 변경

```bash
python code/시연도구.py refresh-overlays \
  --data 01.시연데이터/새_512데이터 \
  --results 03.모델예측/새_전체타일_비교 \
  --alpha 0.5
```

`0`은원본, `0.5`는반투명, `1`은진한단색입니다. 이 명령만 기존 배치 오버레이를 교체합니다. 원본·마스크·모델·정량값은 바꾸지 않으며 `04.시연산출물/`에는 영향을 주지 않습니다.
