# 시연용 실행 안내

플랫폼 표출만 필요하면 [완성된 산출물](../04.시연산출물/README.md)을 사용하십시오. 아래는 재생성·학습·실제 추론을 진행하는 담당자용입니다.

## 실행 환경

Python3.11과 프로젝트 의존성을 설치합니다. 저장소 루트에서 실행하십시오.

```bash
python -m pip install -e ".[test,mesh-gpu]"
```

정량 생성에는 모델·SAM3패키지가 필요하지 않습니다. 모델 학습·추론을 할 때만 루트 [설치 안내](../../README.md)에 따라 SAM3를 설치합니다. 이번에 검증한 SAM3커밋은 `46957e47805eaa273f4aa7bbbd25a88bca9108ce`입니다. 입력·래스터화를 정확히 재현하려면 [검증 환경](학습설명.md)도 확인하십시오.

이하 명령은 저장소의 `06.시연용` 폴더에서 실행합니다. 출력 폴더가 이미 있으면 덮어쓰지 않습니다.

## 1. 원본에서512학습 데이터 준비

```bash
python code/시연도구.py prepare \
  --source 01.시연데이터/원본자료/Daechung_Demo20_GT_release_v1 \
  --output 01.시연데이터/새_512데이터
```

사진을 확대·축소하지 않습니다. CRC는1픽셀 중심선, DLM/SPL은 독립 다각형 마스크로 준비합니다. 배경 타일도 준비되지만 학습에서는 제외하며, 사진 밖 여백은 손실과 정량 계산에서 제외합니다.

## 2. 라벨 기반 정량 산출물 생성 — 모델·GPU 불필요

기존OBJ를 루트 [3D모델 안내](../../README.md)에 따라 준비한 뒤 실행합니다.

```bash
python code/시연도구.py quantify \
  --data 01.시연데이터/새_512데이터 \
  --output 04.시연산출물_재생성 \
  --mesh ../01_RawData/geometry/daecheong_dam_epsg5186_zup.obj
```

기본Ray 계산은CPU입니다. CSV·Excel·원본사진·512원본타일·반투명 라벨 오버레이·계산 기록을 새 폴더에 생성합니다. 승인된16개 컬럼과 기존GSD 계산식을 유지합니다. 정량값의 의미와 빈칸 기준은 [산출물 안내](../04.시연산출물/README.md)를 확인하십시오.

## 3. 추가 학습 — GPU 필요

기존약10GB `checkpoint_final.pt`를 루트모델Release에서 받아 준비합니다. 아래는20회 학습 명령입니다.

```bash
python code/시연도구.py train \
  --data 01.시연데이터/새_512데이터 \
  --checkpoint ../02_Model/sam3_aug512/checkpoints/checkpoint_final.pt \
  --output 02.시연모델/새_20회학습 \
  --epochs 20 --save-every 5
```

손상이 있는489타일의 양성 타일·종류650쌍만 학습합니다. 존재하지 않는 손상 종류를 음성 질의로 추가하지 않습니다. 같은 사진을 학습과 시연에 쓰므로 일반화 성능 평가가 아닙니다. 실행 점검만 하려면 `--epochs 1 --max-steps 6`을 지정할 수 있으나,6단계 결과는 완성 모델이 아닙니다.

## 4. 실제 모델로512타일 한 장 예측

[시연 모델](../02.시연모델/README.md)을 다운로드한 뒤 실행합니다. 현재 저장된 예측은 GPU 환경에서 확인했으며, 이 시연 모델의 CPU 추론은 별도 실행 검증이 필요합니다.

```bash
python code/모델받기.py
python code/시연도구.py predict \
  --image 04.시연산출물/512원본타일/DJI_20250702160538_0800_V__x03584_y01024.png \
  --model-record 02.시연모델/손상타일489개_512입력_20회학습/학습기록.json \
  --output 03.모델예측/새_한장예측
```

라벨을 읽지 않고 모델로만 예측하며, 결과는 라벨과 동일하지 않습니다. 원본 타일·종류별 예측 마스크·모델 오버레이를 따로 저장합니다. 사진 가장자리의 검은 여백이 있는 타일은 연결정보의 유효 폭·높이를 `--valid-width`, `--valid-height`로 전달해야 합니다.

## 5. 새로 학습한 모델의 전체 타일 예측·비교

```bash
python code/시연도구.py predict-batch \
  --data 01.시연데이터/새_512데이터 \
  --model-record 02.시연모델/새_20회학습/학습기록.json \
  --output 03.모델예측/새_전체타일_비교 \
  --selection positive
```

학습에 사용한 것과 동일한 `dataset.json`이 필요하며 해시를 검사합니다. 공개 원본자료는 사진·라벨만 남겨 정리했으므로, 새로 생성한 목록은 기존 학습 당시의 목록과 다릅니다. 기존 시연 모델로 전체 타일을 다시 예측하려면 관리자에게 학습 당시 데이터 묶음을 요청하십시오. 위 명령처럼 새 데이터로 새 모델을 학습한 경우에는 같은 새 데이터를 사용하면 됩니다.

배치 결과는 각 타일에서세 종류를 모두 예측한 뒤 라벨과 비교합니다. 라벨 오버레이와 실제 모델 오버레이를 구분하며, 모델 예측을 라벨로 보정하지 않습니다.

## 6. 저장된 배치 오버레이의 투명도 변경

```bash
python code/시연도구.py refresh-overlays \
  --data 01.시연데이터/새_512데이터 \
  --results 03.모델예측/새_전체타일_비교 \
  --alpha 0.5
```

`0`은원본, `0.5`는반투명, `1`은진한단색입니다. 이 명령만 기존 배치 오버레이를 교체합니다. 원본·마스크·모델·정량값은 바꾸지 않으며 `04.시연산출물/`에는 영향을 주지 않습니다.
