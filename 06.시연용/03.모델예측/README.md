# 실제 모델 예측 확인 자료

`20회학습_손상타일489개_오버레이/`는 저장된 시연 모델로 실제 예측한 결과입니다. 검수 라벨로 예측을 덮어쓰지 않았습니다.

| 폴더 | 내용 |
|---|---|
| `원본타일/` | 512×512 원본 타일489장 |
| `라벨오버레이/` | 검수 라벨을 표시한489장 |
| `모델예측오버레이/` | 실제 모델 예측을 표시한489장 |
| `모델예측마스크/CRC,DLM,SPL/` | 종류별 예측 이진 마스크, 각489장 |

세 이미지 폴더의 같은 파일명은 같은 타일입니다. 오버레이 불투명도는50%이며, 마스크 값은 바꾸지 않았습니다. `배치예측정보.json`의 경로 기준은 그 파일이 있는 배치 결과 폴더입니다.

`재현점검.json`은 학습에 사용한 사진을 다시 비교한 기록입니다. 새로운 사진에 대한 성능 평가가 아니며, 현재 예측은 검수 라벨과 동일하지 않습니다.

[04.시연산출물](../04.시연산출물/README.md)에도 원본 타일·라벨 오버레이·모델 예측 오버레이를 함께 제공합니다. 표출 이미지는 선택할 수 있습니다. 단, 현재 CSV의 손상 위치·정량값은 라벨 기준이며 모델 예측에서 계산한 결과는 아닙니다.
