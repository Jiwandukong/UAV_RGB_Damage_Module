# 대청댐 시연용 자료

플랫폼 담당자가 **손상 표시점·손상정보·512×512 이미지**를 연결하여 시연을 제작할 수 있도록 정리한 폴더입니다.

**시연 산출물은 사람이 검수한 라벨을 기준으로 만들었습니다. 모델이 자동으로 탐지한 정답이라고 표시하면 안 됩니다.** 실제 모델 예측은 별도 폴더에 보존했습니다.

## 먼저 확인할 파일

- [시연용 CSV](04.시연산출물/damage_results.csv)
- [같은 내용의 Excel](04.시연산출물/damage_results.xlsx)
- [산출물 컬럼·이미지 연결 설명](04.시연산출물/README.md)
- [512×512 원본 타일](04.시연산출물/512원본타일/)
- [512×512 라벨 오버레이](04.시연산출물/512라벨오버레이/)

**플랫폼 담당자에게는 `04.시연산출물/`을 통째로 전달하면 됩니다.** CSV·Excel과 연결되는 사진이 모두 들어 있습니다. 이미 생성된 자료를 표출하는 데는 모델 실행·학습·GPU가 필요하지 않습니다. 플랫폼 화면 자체는 전달받는 기관에서 구현합니다.

## 이번 자료의 범위

| 항목 | 내용 |
|---|---|
| 원본 사진 | 20장 |
| 손상 라벨 | 629개: CRC312 / DLM86 / SPL231 |
| 3D 좌표가 있는 행 | 588개 |
| 물리 정량값을 제공하는 행 | 583개 |
| 물리 정량값을 보류한 행 | 46개: Ray 미교차41개, 국부GSD 이상 검토5개 |
| 표출 이미지 | 원본 타일489장 + 라벨 오버레이489장, 각각512×512 |
| 오버레이 | 색상 불투명도50%, 원본 표면이 비치는 반투명 표시 |

**빈칸은0이 아닙니다.** 계산할 수 없거나 검토가 필요한 값은 비워 두었고, 사유와 원계산값은 `04.시연산출물/정량계산기록.json`에 기록했습니다.

## 파일과 이미지 연결

CSV 한 행은 원본 라벨 하나입니다. 손상이 여러 타일에 걸쳐도 행과 정량값을 반복하지 않습니다.

- `source_image_path`: 잘리기 전 원본 JPG 경로
- `tile_original_paths_json`: 해당 손상의 원본 타일 경로 배열
- `tile_overlay_paths_json`: 같은 순서로 대응하는 라벨 오버레이 경로 배열

위 경로는 모두 **`04.시연산출물/` 기준 상대경로**입니다. 타일 배열의 첫 번째 항목이 대표점에 대응하는 기본 표출 이미지입니다. `연결정보.json`에는 원래 라벨 ID와 타일 시작 위치 `x0/y0`가 있습니다.

`pixel_nodes_json`은 타일 좌표가 아니라 **잘리기 전 원본 사진 좌표**입니다. 타일에 그릴 때는 해당 타일의 `x0/y0`를 뺍니다. 가장자리 타일은 원본을 늘리지 않고 사진 밖 부분만 검게 채웠습니다.

## 손상 종류와 정량값

| 라벨 | 의미 | 색상 | 제공하는 정량값 |
|---|---|---|---|
| CRC | Crack / 균열 | 초록 | 회전사각형의 길이·폭: px, m |
| DLM | Delamination / 박리 | 파랑 | 라벨 영역의 근사 면적: m² |
| SPL | Spalling / 박락 | 노랑 | 라벨 영역의 근사 면적: m² |

좌표는 기존 `dam - Cloud.obj`를 사용하며 X/Y는EPSG:5186, Z는기존OBJ의 Z-up 고도입니다. 새GLB를 사용하지 않았습니다.

**CRC 폭은 실제 균열이 벌어진 폭이 아닙니다.** 기존 방식대로 라벨 전체를 감싸는 최소면적 회전사각형의 짧은 변을 환산한 값입니다. 길이도 중심선을 따라 합산한 길이가 아닙니다. 이 정량화 방식은 유지했습니다. 모든 물리 정량값은 시연용 근사치이며, 실제 개구폭 측정·측량·구조 안전 판정에 사용할 수 있는 검증값이 아닙니다.

## 모델이 필요한 경우

완성된 시연 자료를 표출할 때는 모델이 필요하지 않습니다. 모델 자체를 실행하려는 경우에만 [모델 전달 안내](02.시연모델/README.md)를 확인하십시오.

이번 추가 학습 모델은 약3.37GB이며 일반Git에 포함하지 않습니다. **시연용 모델의 Release 다운로드는 아직 게시하지 않았습니다.** 필요하면 관리자에게 별도로 전달받아야 합니다. 기존 저장소 Release의 약10GB 시작 모델과는 다른 파일입니다.

학습은 실제512×512 입력, 손상이 있는489타일,20회·13,000단계로 진행했습니다. 모델 예측은 라벨과 완전히 같지 않습니다. [실제 예측 확인 자료](03.모델예측/README.md)와 [학습 결과](학습결과.md)를 함께 참고하십시오.
