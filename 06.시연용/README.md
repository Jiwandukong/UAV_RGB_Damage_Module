# 대청댐 손상 시연 자료

**원본 사진 → SAM3 추론 → 손상 좌표·정량값·이미지 표출**에 사용하는 자료입니다. 실제 모델 추론 결과와 라벨 기준 참고 결과를 각각 제공합니다.

**이 `06.시연용` 폴더만으로 사용할 수 있습니다.** 다른 번호의 폴더는 필요하지 않습니다. 이미 만들어진 CSV·이미지를 확인할 때는 설치나 모델 실행도 필요하지 않습니다.

## 모델 추론 실행

아래 명령은 모두 **`06.시연용` 폴더 안에서** 실행합니다. 원본 사진을 입력하면 모델이 손상을 예측하고 CSV·Excel·오버레이를 생성합니다. 라벨 파일이나 재학습은 필요하지 않습니다.

### 1. 실행환경 설치 — 처음 한 번

Python 3.11과 Git이 필요합니다. 아래 추론 명령은 **NVIDIA GPU 사용 기준**이며, 이 시연 모델의 전체 원본 추론을 GPU 환경에서 검증했습니다.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install "git+https://github.com/facebookresearch/sam3.git@46957e47805eaa273f4aa7bbbd25a88bca9108ce"
```

### 2. SAM3 모델과 댐 OBJ 다운로드 — 처음 한 번

```bash
python code/모델받기.py
python code/3D모델받기.py
```

두 파일 모두 `02.시연모델/` 안에 저장됩니다. 다운로드가 되지 않으면 아래 [모델과 플랫폼 연결](#모델과-플랫폼-연결)의 안내에 따라 파일을 직접 전달받아 같은 위치에 넣으십시오.

### 3. 원본 사진 한 장 추론

포함된 원본 사진 한 장을 실행하는 명령입니다.

```bash
python code/시연도구.py infer \
  --images "01.시연데이터/원본자료/Daechung_Demo20_GT_release_v1/01_Dataset/images/DJI_20250702150745_0300_V.JPG" \
  --model-record "02.시연모델/손상타일489개_512입력_20회학습/학습기록.json" \
  --mesh "02.시연모델/댐3D모델/daecheong_dam_epsg5186_zup.obj" \
  --output "04.시연산출물/새_모델추론결과" \
  --device cuda
```

- **다른 사진 사용:** `--images`를 원하는 원본 사진 경로로 바꿉니다. 사진 폴더를 지정하면 바로 아래의 JPG·JPEG·PNG를 모두 처리합니다.
- **저장 위치 변경:** `--output`을 원하는 새 폴더 경로로 바꿉니다. 기존 폴더는 덮어쓰지 않으므로 다시 실행할 때도 새 경로를 지정합니다.
- **다음 실행:** `source .venv/bin/activate` 후 추론 명령만 실행하면 됩니다. 설치·다운로드를 반복할 필요는 없습니다.

완료되면 위 명령의 **`04.시연산출물/새_모델추론결과/`** 안에 다음 결과가 생성됩니다.

- `damage_results.csv`, `damage_results.xlsx`: 모델이 예측한 손상의 좌표·정량값·이미지 연결 경로
- `원본사진/`, `512원본타일/`: 입력 원본과 512×512로 자른 원본 이미지
- `512모델예측오버레이/`: 각 타일에 모델 예측을 반투명 색상으로 표시한 이미지
- `연결정보.json`: 손상 ID와 타일, 원본 내 타일 위치의 연결 정보

좌표나 물리 정량값을 계산하지 못한 항목은 빈칸으로 남습니다. 기존 라벨 기준 결과나 아래 제공된 모델 추론 결과를 덮어쓰지 않습니다.

경로는 `06.시연용/` 기준입니다. 이 묶음의 CSV와 이미지는 모두 **모델이 예측한 손상**에 대응합니다.

| 자료 | 위치 | 의미 |
|---|---|---|
| 추론 결과 CSV | [04.시연산출물/모델추론결과/damage_results.csv](04.시연산출물/모델추론결과/damage_results.csv) | 예측 손상별 위치·정량값·이미지 경로 |
| 추론 결과 Excel | [04.시연산출물/모델추론결과/damage_results.xlsx](04.시연산출물/모델추론결과/damage_results.xlsx) | CSV와 같은 내용 |
| 원본 사진 | [04.시연산출물/모델추론결과/원본사진/](04.시연산출물/모델추론결과/원본사진/) | 자르기 전 입력 사진 |
| 처리된 원본 이미지 | [04.시연산출물/모델추론결과/512원본타일/](04.시연산출물/모델추론결과/512원본타일/) | 원본 전체 영역을 512×512로 자른 이미지 |
| 모델 오버레이 | [04.시연산출물/모델추론결과/512모델예측오버레이/](04.시연산출물/모델추론결과/512모델예측오버레이/) | 같은 파일명의 타일에 예측 손상을 표시한 이미지 |
| 손상·타일 연결 정보 | [04.시연산출물/모델추론결과/연결정보.json](04.시연산출물/모델추론결과/연결정보.json) | 손상 ID와 해당 타일, 원본 내 타일 위치 |

원본 타일과 모델 오버레이의 **같은 파일명은 같은 이미지 영역**입니다. CSV의 `tile_original_paths_json`과 `tile_overlay_paths_json`이 같은 순서로 대응합니다. 경로 기준은 **해당 CSV가 있는 폴더**입니다.

표출용·정량용 컬럼의 뜻: [모델 추론 산출물 설명](04.시연산출물/모델추론결과/README.md). 빈칸은 0이 아니라 해당 없음 또는 계산 보류입니다.

라벨과 모델 예측은 같지 않습니다. **각 결과의 CSV를 해당 결과 폴더의 이미지와 함께 사용하십시오.** 같은 `damage_id`라도 서로 다른 결과 묶음 사이에서는 같은 손상을 뜻하지 않습니다.

색상은 **CRC = Crack(균열, 초록), DLM = Delamination(박리, 파랑), SPL = Spalling(박락, 노랑)**이며, 오버레이 불투명도는 50%입니다.
