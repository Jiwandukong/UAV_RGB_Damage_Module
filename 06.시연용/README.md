## 이미지와 CSV의 관계

세 이미지 폴더에서 **같은 파일명은 같은 512×512 타일**입니다. 라벨 오버레이와 모델 예측 오버레이를 나란히 비교할 수 있으며, 사용할 이미지는 선택할 수 있습니다.

- 원본: `512원본타일/파일명.png`
- 라벨 표시: `512라벨오버레이/파일명.png`
- 모델 예측 표시: `512모델예측오버레이/파일명.png`

**현재 CSV의 위치·정량값과 `tile_overlay_paths_json`은 라벨 기준입니다. 모델 오버레이에서 계산한 CSV가 아닙니다.** 모델 오버레이는 같은 타일 파일명을 통해 연결되며, 라벨과 예측 결과는 동일하지 않습니다.

CSV 안의 이미지 경로는 `04.시연산출물/` 기준 상대경로입니다. 각 컬럼의 뜻은 [표출용·정량용 컬럼 설명](04.시연산출물/README.md)을 참고하십시오. 빈칸은 0이 아니라 해당 없음 또는 계산 보류입니다.

색상은 **CRC = Crack(균열, 초록), DLM = Delamination(박리, 파랑), SPL = Spalling(박락, 노랑)**입니다. 두 종류의 오버레이 모두 불투명도 50%입니다.

## 플랫폼 시연 범위

예정된 흐름은 **원본 사진 입력 → 모델 추론 → 결과 표출**입니다. 현재 시연 모델은 512×512 타일 추론을 지원하며, 원본 사진 입력부터 모델 추론 기반 좌표·CSV 생성까지의 통합 연결은 아직 완료되지 않았습니다.

모델 저장 위치와 다운로드 안내: [시연 모델](02.시연모델/README.md). 사진·라벨·모델의 이용 조건: [자료 출처](권리_및_자료출처.md).
