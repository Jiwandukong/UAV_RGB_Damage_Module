# 대청댐 손상 시연 자료

**원본 사진 → SAM3 추론 → 손상 좌표·정량값·이미지 표출**에 사용하는 자료입니다. 실제 모델 추론 결과와 라벨 기준 참고 결과를 각각 제공합니다.

## 모델 추론 결과

경로는 `06.시연용/` 기준입니다. 이 묶음의 CSV와 이미지는 모두 **모델이 예측한 손상**에 대응합니다.

| 자료 | 위치 | 의미 |
|---|---|---|
| 추론 결과 CSV | [04.시연산출물/모델추론결과/damage_results.csv](04.시연산출물/모델추론결과/damage_results.csv) | 예측 손상별 위치·정량값·이미지 경로 |
| 추론 결과 Excel | [04.시연산출물/모델추론결과/damage_results.xlsx](04.시연산출물/모델추론결과/damage_results.xlsx) | CSV와 같은 내용 |
| 원본 사진 | [04.시연산출물/모델추론결과/원본사진/](04.시연산출물/모델추론결과/원본사진/) | 자르기 전 입력 사진 |
| 처리된 원본 이미지 | [04.시연산출물/모델추론결과/512원본타일/](04.시연산출물/모델추론결과/512원본타일/) | 원본 전체 영역을 512×512로 자른 이미지 |
| 모델 오버레이 | [04.시연산출물/모델추론결과/512모델예측오버레이/](04.시연산출물/모델추론결과/512모델예측오버레이/) | 같은 파일명의 타일에 예측 손상을 표시한 이미지 |
| 손상·타일 연결 정보 | [04.시연산출물/모델추론결과/연결정보.json](04.시연산출물/모델추론결과/연결정보.json) | 손상 ID와 해당 타일, 원본 내 타일 위치 |

원본 타일과 모델 오버레이의 **같은 파일명은 같은 이미지 영역**입니다. CSV의 `tile_original_paths_json`과 `tile_overlay_paths_json`이 같은 순서로 대응합니다. 경로 기준은 **해당 CSV가 있는 폴더**입니다.

표출용·정량용 컬럼의 뜻: [모델 추론 산출물 설명](04.시연산출물/모델추론결과/README.md). 빈칸은 0이 아니라 해당 없음 또는 계산 보류입니다.

| 같은 타일의 모델 오버레이 | [04.시연산출물/512모델예측오버레이/](04.시연산출물/512모델예측오버레이/) | 위 489타일에 대응하는 모델 예측 비교 이미지 |

라벨과 모델 예측은 같지 않습니다. **각 결과의 CSV를 해당 결과 폴더의 이미지와 함께 사용하십시오.** 같은 `damage_id`라도 서로 다른 결과 묶음 사이에서는 같은 손상을 뜻하지 않습니다.

색상은 **CRC = Crack(균열, 초록), DLM = Delamination(박리, 파랑), SPL = Spalling(박락, 노랑)**이며, 오버레이 불투명도는 50%입니다.

## 모델과 플랫폼 연결

- 시연 모델: [SAM3 512×512 Release](https://github.com/Jiwandukong/UAV_RGB_Damage_Module/releases/tag/sam3-demo512-v1), 약 3.37GB. [저장 위치](02.시연모델/README.md)
- 3D 모델: [기존 대청댐 OBJ Release](https://github.com/Jiwandukong/UAV_RGB_Damage_Module/releases/tag/daecheong-dam-geometry-v1)
- 원본 사진 추론 호출: [플랫폼 연결용 실행 명령](code/플랫폼추론.md). 사진 한 장 또는 폴더를 입력받고, 라벨 없이 위 형식의 결과를 생성합니다.

사진·라벨·모델의 이용 조건: [자료 출처](권리_및_자료출처.md).
