# 512×512 손상 타일 학습 결과

## 완료 범위

원본20장에서 손상이 있는489개 타일을 골라20회 반복 학습했습니다. 각 반복에서 실제 라벨이 있는 타일·손상종류650쌍(CRC262 / DLM112 / SPL276)을 각각 한 번씩 사용하여 총13,000단계입니다. 배경만 있는1,271개 타일과 해당 타일에 없는 종류의 학습 질의는 제외했습니다.

- 실제 모델 입력: `[1,3,512,512]`. 확대·축소 없음. 실제 패치 입력도 후크로 확인했습니다.
- 정답 마스크: `[1,1,512,512]`. CRC 중심선 두께1픽셀, 가장자리 여백은 손실에서 제외.
- 학습 범위: 기존 SAM3의 융합 인코더와 픽셀/semantic 분할부10,917,633개 파라미터. 영상·텍스트 백본은 고정.
- 시작 가중치: 사용자가 제공한 기존 `checkpoint_final.pt`. 공식 Foundation 원본 체크포인트에서 새로 시작한 학습이 아니라, 제공된 SAM3 체크포인트에 대한 추가 학습입니다.
- 학습·저장 기록 시간: **737.95초, 약12분18초**.
- 최종 모델로489개 타일 예측·오버레이·비교 기록 시간: **90.58초, 약1분31초**.
- GPU: NVIDIA GeForce RTX4090. 최고 학습 텐서 할당 메모리3,859,980,800바이트. 이는 GPU 전체 사용량과는 다른 측정값입니다.

사용할 모델은 `02.시연모델/손상타일489개_512입력_20회학습/sam3_demo512_학습완료.pt`입니다. 크기3,367,960,745바이트(약3.37GB)이며, optimizer를 제외한 모델 가중치와 시연 설정을 저장했습니다. 기존 모델 파일은 변경하지 않았습니다.

```text

eb6489ba6e5aa9b307aef1f1d2b86037ff91d40e22f0deb98e8c704d286079d5
```

같은 폴더의 `학습기록.json`을 모델 파일과 함께 전달해야 합니다. 5·10·15회 중간 모델도 보존했습니다. 이들은 optimizer/RNG까지 보존한 정확한 학습 재개 파일은 아닙니다.

`03.모델예측/20회학습_손상타일489개_오버레이/`에 다음을 따로 저장했습니다.

| 폴더 | 내용 | 수량 |
|---|---|---:|
| `원본타일/` | 확대·축소하지 않은512×512 사진 | 489장 |

각 폴더에서 같은 파일명끼리 대응합니다. `배치예측정보.json`에는 타일 ID, 기존 손상 ID, 원본 위치, 각 이미지 경로가 있습니다. 모든 경로는 이 배치 결과 폴더 기준 상대경로입니다. 모델 오버레이는 라벨로 보정하지 않았습니다.

표출 이미지에는 이후 **색상 불투명도50%**를 적용했습니다. 라벨489장·모델 예측489장만 원본과 마스크에서 다시 합성하며, 재학습·재추론이나 손상 위치·마스크·정확도 변경은 없습니다. `오버레이변경기록.json`에 변경 내역을 남기고, 학습 당시 `01.시연데이터/`와 모델 기록은 보존합니다. 위90.58초는 최초 예측 실행 기록이며 투명도 변경 시간은 포함하지 않습니다.

## 정답과 얼마나 일치했나요?

**학습에 사용한 사진을 다시 확인한 수치이며, 새로운 사진에 대한 성능 평가가 아닙니다.** 489개 타일 각각에서 세 종류를 모두 예측하고, 정확히 같은 위치의 픽셀을 비교했습니다. 임계값0.5, 좌표 허용오차·마스크 팽창·형태 보정은 사용하지 않았습니다. 사진 밖 여백은 제외했습니다.

IoU는 정답과 예측이 겹치는 정도입니다. 100%이면 해당 픽셀 마스크가 같습니다.

| 손상 | 전체489타일에서의 IoU | 그 손상 라벨이 실제로 있는 타일만 비교한 IoU |
|---|---:|---:|
| CRC 균열 | **10.92%** | 19.15% |
| DLM 박리 | **39.91%** | 93.37% |
| SPL 박락 | **72.82%** | 91.90% |

오른쪽 열은 부재 클래스의 오탐을 제외하므로, 전체 결과 설명에는 왼쪽 열을 사용해야 합니다. 상세 TP/FP/FN/TN, 정밀도·재현율·F1은 `재현점검.json`에 저장했습니다.

### 해석과 남은 문제

- **정답과 동일한 모델 예측은 아직 아닙니다.** 특히1픽셀 CRC 중심선보다 넓은 영역을 예측합니다. CRC는 정답63,802픽셀에 대해564,827픽셀을 예측했고, 그중61,900픽셀이 일치했습니다.
- DLM·SPL은 해당 손상이 있는 타일에서는 잘 맞는 경우가 많지만, 없는 종류를 잘못 표시하는 경우가 있습니다. 예를 들어 DLM의 오탐3,035,089픽셀 중2,973,565픽셀은 DLM 라벨이 없는 타일에서 발생했습니다.
- 존재하는 손상 종류만 학습하고 부재 클래스 질의를 학습에서 제외한 설정은 이 오탐과 관련될 수 있습니다. 이번 작업에서 이 규칙을 임의로 바꾸거나 음성 학습을 추가하지 않았습니다. 원인을 확정한 실험은 아닙니다.
- 내부 분할 출력은148격자에서512좌표로 복원됩니다. 1픽셀 정답을 사용했다는 사실이 예측도1픽셀이라는 뜻은 아닙니다. 이 차이를 실제 균열 폭으로 환산해서는 안 됩니다.
- **요청한 라벨 기반 시연 자료는 별도로 정확히 보존돼 있습니다.** 라벨 오버레이를 모델 예측 결과라고 혼동하지 않도록 폴더를 분리했습니다.

## 검증

- 최초 학습 시 자동 테스트31개 통과. 이후 오버레이 투명도 변경·재생성까지 포함하여53개 통과.
- 정량 산출물 추가 후 시연 도구와 기존Ray·GSD·산출물 관련 기능을 함께 검사하여141개 통과. CSV·Excel16열·629행과 모든 이미지 연결, 원본 해시,50%오버레이를 별도로 검증했습니다.
- 학습 로그13,000단계의 순번·양성 타일·각 반복의650쌍·입력 크기 확인. 손실과 기울기 노름은 모두 유한합니다.
- 최종 모델1,134개 상태 항목을 기존 모델과 비교: 학습 대상124개 텐서는 모두 변경됐고, 고정 영상438·텍스트295·기타273개 항목은 그대로입니다. 나머지4개는512입력 대응을 위한 정상적인 위치 인코딩 버퍼 크기 변경입니다.
- 원본 체크포인트 SHA256 유지, 새 모델 SHA256 검증, 새 프로세스에서 strict 재로딩 후 전체 타일 예측 완료.

이후 검수 라벨을 기준으로 [시연용 CSV·Excel](04.시연산출물/README.md)도 생성했습니다. 모델 예측을 정답으로 간주하여 계산한 것이 아닙니다. 라벨629행 중588행의 대표점이 기존OBJ에 매핑되었고583행에 물리 정량값을 기록했습니다. Ray 미교차41행과GSD 이상 검토5행의 정량값은 빈칸으로 남기고 사유·원계산값을 별도JSON에 기록했습니다. CSV는 기존16개 열을 유지하며512원본·반투명 라벨 오버레이와 연결됩니다.

원본 자료·완성 산출물·실제 예측 확인 자료·학습 기록은 이번 시연 폴더의 공개 범위입니다. 학습 체크포인트는 일반Git에서 제외하며, 시연 모델Release는 아직 게시하지 않았습니다. [모델 전달 안내](02.시연모델/README.md)를 참고하십시오. 플랫폼 화면 자체는 구현하지 않습니다.
