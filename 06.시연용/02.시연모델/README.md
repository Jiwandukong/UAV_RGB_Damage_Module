# 시연용 학습 모델

시연 CSV와 라벨 오버레이를 플랫폼에서 표시하는 데는 모델이 필요하지 않습니다. [완성 산출물](../04.시연산출물/README.md)을 사용하면 됩니다.

이 폴더에는 최종20회 학습의 `학습기록.json`과 `학습진행.jsonl`을 게시합니다. 체크포인트 가중치는 일반 Git에 포함하지 않습니다.

| 항목 | 내용 |
|---|---|
| 파일 | `sam3_demo512_학습완료.pt` |
| 크기 | 3,367,960,745바이트, 약3.37GB |
| SHA256 | `eb6489ba6e5aa9b307aef1f1d2b86037ff91d40e22f0deb98e8c704d286079d5` |
| 입력 | 실제512×512 RGB |
| 학습 대상 | 손상이 있는489타일,20회·13,000단계 |

**이 시연용 체크포인트의 다운로드 Release는 아직 게시하지 않았습니다.** 모델 추론이 필요한 경우 관리자에게 위 파일을 별도로 전달받아 다음 위치에 저장하십시오.

```text
02.시연모델/손상타일489개_512입력_20회학습/sam3_demo512_학습완료.pt
```

같은 폴더의 [학습기록.json](손상타일489개_512입력_20회학습/학습기록.json)으로 파일 해시를 검사하고 불러옵니다. 기록에 남은 과거 절대경로는 실행 출처이며, 모델 로딩 경로는 이 기록의 `checkpoint.file`을 기준으로 결정됩니다.

기존 저장소 Release의 약10GB `checkpoint_final.pt`는 이번 추가 학습의 시작 모델이며, 위3.37GB 시연 모델과 다른 파일입니다. 이름만 바꿔서 대신 사용할 수 없습니다.

학습 사진을 다시 예측한 결과도 라벨과 완전히 일치하지 않습니다. [학습 결과](../학습결과.md)와 [실제 모델 예측 이미지](../03.모델예측/README.md)를 확인하십시오.
