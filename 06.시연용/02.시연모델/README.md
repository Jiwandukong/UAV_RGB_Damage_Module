# 시연 모델 받기

완성된 CSV와 라벨 오버레이를 표시할 때는 모델이 필요하지 않습니다. **SAM3를 직접 실행할 때만** 아래 파일을 준비하십시오.

시연용 모델은 `sam3_demo512_학습완료.pt`(약 3.37GB)입니다. **시연 모델 Release는 아직 게시하지 않았으므로 관리자에게 별도로 전달받아야 합니다.**

받은 파일을 `06.시연용/` 기준 다음 위치에 놓으십시오.

```text
02.시연모델/손상타일489개_512입력_20회학습/sam3_demo512_학습완료.pt
```

같은 폴더의 `학습기록.json`은 Git에 포함되어 있습니다. 파일명을 바꾸지 않으면 실행 시 이 기록으로 모델을 찾아 검사합니다.

- 실행 방법: [512×512 이미지 한 장 예측](../code/실행안내.md#4-실제-모델로512타일-한-장-예측)
- 이미 만들어진 결과: [모델 예측 오버레이](../03.모델예측/20회학습_손상타일489개_오버레이/모델예측오버레이/)

기존 Release의 약 10GB `checkpoint_final.pt`는 추가 학습을 시작할 때 쓰는 별도 모델입니다. 위 시연 모델 대신 사용할 수 없습니다.
