# 시연 모델 받기

완성된 CSV와 이미지를 표시할 때는 모델이 필요하지 않습니다. **SAM3를 직접 실행할 때만** 아래 파일을 준비하십시오.

시연용 모델은 `sam3_demo512_학습완료.pt`(약 3.37GB)입니다. [시연 모델 Release](https://github.com/Jiwandukong/UAV_RGB_Damage_Module/releases/tag/sam3-demo512-v1)에 2개로 나누어 제공합니다.

`06.시연용/`에서 실행하면 두 파일을 받고, 하나의 모델로 복원한 뒤 SHA256으로 검사합니다. 다운로드 도구에는 Python 표준 라이브러리만 필요하며, 다른 번호의 폴더는 필요하지 않습니다.

```bash
python code/모델받기.py
```

다운로드·복원 중 약 6.8GB의 여유 공간이 필요합니다. 모델은 다음 위치에 저장됩니다.

```text
02.시연모델/손상타일489개_512입력_20회학습/sam3_demo512_학습완료.pt
```

같은 폴더의 `학습기록.json`은 Git에 포함되어 있습니다. 파일명을 바꾸지 않으면 실행 시 이 기록으로 모델을 찾아 검사합니다.

다운로드나 복원이 안 되면 관리자에게 약 3.37GB 원본 파일을 직접 전달받아 위 위치에 놓으십시오.

- 설치·실행: [원본 사진 → CSV·오버레이](../code/플랫폼추론.md)
- 좌표 계산용 모델: [댐 3D 모델 받기](댐3D모델/README.md)
- 이미 만들어진 결과: [모델 추론 산출물](../04.시연산출물/모델추론결과/README.md)

기존 Release의 약 10GB `checkpoint_final.pt`는 추가 학습을 시작할 때 쓰는 별도 모델입니다. 위 시연 모델 대신 사용할 수 없습니다.

현재 모델 예측은 GPU 환경에서 확인했으며 **라벨과 동일하지 않습니다.** 라벨 기준 시연 오버레이·CSV와 구분하여 사용하십시오.
