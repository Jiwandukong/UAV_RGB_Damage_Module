# 원본 사진과 검수 라벨

`원본자료/Daechung_Demo20_GT_release_v1/`에는 제공받은 원본 자료66개를 변경 없이 보존했습니다. 촬영 사진20장, 대응하는 LabelMe JSON20개, 검수 문서와 참고 이미지가 포함됩니다. 원본 문서의 과거 작업 경로는 출처 기록이며, 이 컴퓨터에 그 경로를 만들 필요는 없습니다.

플랫폼 표출만 할 때는 이 폴더를 처리하지 않아도 됩니다. [완성된 시연 산출물](../04.시연산출물/README.md)을 사용하십시오.

512×512 학습 타일·마스크와 `dataset.json`은 용량을 줄이기 위해 Git에서 제외했습니다. 재생성이 필요하면 `06.시연용` 폴더에서 다음 명령을 실행합니다.

```bash
python code/시연도구.py prepare \
  --source 01.시연데이터/원본자료/Daechung_Demo20_GT_release_v1 \
  --output 01.시연데이터/새_512데이터
```

이후 학습 또는 정량 생성 명령의 `--data`에는 `01.시연데이터/새_512데이터`를 지정합니다. 기존 폴더는 덮어쓰지 않습니다.

학습 당시의 타일 묶음은 별도로 보존되어 있습니다. 새로 준비한 데이터는 표시 설정·라이브러리 버전 등에 따라 `dataset.json` 해시가 달라질 수 있습니다. 이전 학습 기록과 해시가 다르면 배치 재현 검증은 중단하며, 검사를 우회하지 않습니다. 이전 모델의 엄밀한 배치 재현에 필요한 원래 데이터 묶음은 관리자에게 요청하십시오.
